# Fork policy

This repository is the `oriyano/Pinta` fork of `PintaProject/Pinta`.

Keep changes to this fork. Do not create or submit pull requests, patches, or other code contributions to `PintaProject/Pinta` from this repository. Do not push to the `upstream` remote. The `upstream` remote may be used to fetch changes for this fork.

This policy applies to all future work in this repository unless the repository owner explicitly changes it.
